# Poker Timer — блайнд-таймер турнира

Настраиваемый турнирный таймер блайндов для домашнего стола или клубного ТВ.  
Статический сайт: всё считается в браузере, данные хранятся в `localStorage`.

**Live:** https://ve1lers.github.io/poker-timer/

Вдохновлён [pokersystem.ru/timer](https://pokersystem.ru/timer), с более гибкой структурой уровней и экспортом.

## Возможности

- Уровни: длительность, МБ/ББ, анте, перерывы
- Крупный обратный отсчёт, пауза / старт, предыдущий / следующий уровень
- Превью следующего уровня, прошедшее и оставшееся время турнира
- Игроки в игре / всего, средний стек (от стартового стека)
- Пресеты: домашняя, турбо, обычная, глубокая
- Редактор структуры: добавить / удалить / переставить уровни
- Сохранение своих структур, экспорт / импорт JSON
- Звук смены уровня, гонг перерыва, аплодисменты в конце турнира, предупреждение за N секунд
- Темы: тёмная / светлая, акценты (золото, сукно, бордо, лёд)
- Полный экран и Wake Lock (экран не гаснет)

## Как пользоваться

1. Откройте сайт на ноутбуке или ТВ-браузере.
2. **Настройки** → вкладка **Структура** или выберите пресет на вкладке **Турнир**.
3. Задайте игроков и стартовый стек.
4. Нажмите **Применить**, затем ▶ на табло.
5. Клавиши: `Space` — старт/пауза, `←` / `→` — уровни.

## Как править блайнды

- В **Настройках → Структура** меняйте минуты, блайнды и анте в таблице.
- **+ Уровень** / **+ Перерыв** — добавить строку; стрелки — порядок; × — удалить.
- **Данные → Экспорт JSON** — скачать структуру; **Импорт JSON** — загрузить обратно.
- **Сохранить структуру как** — именованный пресет в этом браузере.

Пример фрагмента JSON:

```json
{
  "name": "Мой турнир",
  "startStack": 10000,
  "levels": [
    { "duration": 15, "sb": 25, "bb": 50, "ante": 0, "isBreak": false },
    { "duration": 10, "sb": 0, "bb": 0, "ante": 0, "isBreak": true }
  ]
}
```

## Локальный запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
npx --yes serve .
```
